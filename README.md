# Machine Learning Portfolio

Welcome to my Machine Learning Portfolio. This repository contains my laboratory activities, machine learning projects, assignments, and examination work completed as part of my academic coursework.

The repository brings together practical work covering Python programming, data preprocessing, exploratory data analysis, machine learning, classification, feature engineering, dimensionality reduction, neural networks, and natural language processing.
